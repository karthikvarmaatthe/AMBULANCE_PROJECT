⚙️ System Architecture & Telemetry Specs

🗺️ Map & Tile Infrastructure

  • Engine: Leaflet.js Standard Architecture
  • Tiles: OpenStreetMap Standard (tile.openstreetmap.org)
  • Watermarks: Zero watermarks, zero CARTO dependencies
  • API Keys: Zero external API keys required
  • Attribution: © OpenStreetMap contributors

🧠 Routing & Optimization Engine

  • Algorithm: Dijkstra Shortest Path with Min-Heap Priority Queue
  • Multi-Route Engine: Yen's K-Shortest Alternative Corridors (K=3)
  • Cost Metric: Travel Time with Live Traffic Congestion Multipliers
  • Coverage: 113 Junctions, 149 Bidirectional Roads, 78 Areas
  • Snapping: Haversine Nearest-Node Geometric Snapping

💾 Storage & Runtime Specifications

  • Database: SQLite Local Database (ambulance.db)
  • Server Backend: Python 3 + Flask Full-Stack Architecture
  • Android Runtime: Jetpack Compose + Native WebView Integration
  • Audio Engine: Web Audio API Emergency Siren & Arrival Chimes
